LinkedListImplementation

Files:
1. SinglyLinkedList.java
2. DoublyLinkedList.java
3. CircularLinkedList.java

Each class uses Object data so a node can store different kinds of Java objects.
Each class has length(), insertion, deletion, searching, updating, display, and clear operations.
Singly and doubly linked lists also have reverse().

Run each file separately with a JDK:
javac SinglyLinkedList.java
java SinglyLinkedList

javac DoublyLinkedList.java
java DoublyLinkedList

javac CircularLinkedList.java
java CircularLinkedList
